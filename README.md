# Sanket
Sanket — Where Hands Speak. A deep learning app that translates Indian Sign Language into text and speech in real time.

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/1b8a9052-3680-4d21-836b-62893919d668

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Dataset

`dataset/American Hand Signs Dataset.zip` (392 MB) is not included in this repo because it exceeds GitHub's 100 MB file limit.
